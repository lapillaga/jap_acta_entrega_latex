\chapter{Hoja de Accesos y Credenciales}

Este capítulo documenta los accesos a sistemas, cuentas bancarias, correos electrónicos, almacenamiento en la nube y otras plataformas digitales utilizadas por la Junta. Por seguridad, \textbf{NO} se incluyen contraseñas en este documento. La transferencia de credenciales se realiza de forma segura durante la entrega-recepción presencial.

\section*{Importancia de la transferencia segura}

Las credenciales de acceso son información sensible que debe manejarse con responsabilidad. La nueva directiva debe:

\begin{itemize}
  \item Recibir las credenciales de forma presencial y confidencial
  \item Cambiar todas las contraseñas dentro de las 48 horas siguientes a la entrega-recepción
  \item Mantener las credenciales en lugar seguro y no compartirlas innecesariamente
  \item Designar responsables claros para cada sistema
  \item Implementar autenticación de dos factores donde sea posible
\end{itemize}

\section*{Protocolo de Seguridad}

\subsection*{Durante la entrega-recepción (31 de octubre de 2025)}

\begin{enumerate}
  \item La directiva saliente entrega las credenciales de forma presencial y confidencial
  \item Los nuevos responsables verifican acceso a cada sistema en presencia de la directiva saliente
  \item Se firma acta de recepción de credenciales (documento separado, confidencial)
  \item Se registra en el check-list los sistemas transferidos exitosamente
\end{enumerate}

\subsection*{Dentro de las 48 horas posteriores (plazo: 02 de noviembre de 2025)}

\begin{enumerate}
  \item Cambiar todas las contraseñas a claves nuevas y seguras
  \item Activar autenticación de dos factores donde sea posible
  \item Actualizar correos de recuperación y números de teléfono de contacto
  \item Verificar nuevamente el acceso con las nuevas credenciales
  \item Notificar a la directiva cualquier problema de acceso
\end{enumerate}

\subsection*{Recomendaciones de seguridad}

\begin{itemize}
  \item \textbf{Contraseñas seguras:} Usar combinación de letras mayúsculas, minúsculas, números y símbolos (mínimo 12 caracteres)
  \item \textbf{No reutilizar:} Cada sistema debe tener una contraseña diferente
  \item \textbf{Administrador de contraseñas:} Considerar uso de aplicación segura para gestionar contraseñas (ej. Bitwarden, 1Password)
  \item \textbf{Respaldo:} Mantener respaldo físico de usuarios (no contraseñas) en lugar seguro de la oficina
  \item \textbf{Actualización:} Cambiar contraseñas periódicamente (cada 3--6 meses)
  \item \textbf{Confidencialidad:} No compartir credenciales por correo, WhatsApp u otros medios inseguros
\end{itemize}

\textit{Nota final:} Este capítulo documenta únicamente los sistemas y responsables. Las credenciales reales (usuarios y contraseñas) se transfieren mediante acta confidencial separada durante la entrega-recepción presencial. La nueva directiva asume la responsabilidad de proteger adecuadamente esta información y de cambiar las contraseñas dentro del plazo establecido.
